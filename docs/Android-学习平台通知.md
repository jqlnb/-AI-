# Android 学习平台通知接入

1. 安装 Android APK 并登录账号（登录用于同步任务，不是读取学习平台账号）。
2. 打开“消息识别 → 学习平台通知接入”，点击“打开 Android 通知授权”。在系统页面里只为本应用打开通知读取权限，再返回助手。
3. 返回助手后点“扫描通知中心并处理”。授权后仍留在通知栏中的通知会被回扫；如果列表里还没有学习通/智慧树，先确保平台通知还留在通知栏，再扫描一次。
4. 在应用列表中勾选“学习通”或“智慧树”，不要勾选截图工具等其他应用；启用后会立即扫描当前通知，后续新通知也会自动处理。只有勾选的平台应用会读取正文。
5. 作业通知标题/正文会在手机本地解析为待办并同步到 Supabase。平台通知标题为“通知”时会尝试从正文提取作业标题；截止时间未明确时留空并标记“截止时间待补充”。同一 Android 通知通过稳定来源 ID 去重。

要停止接入，可关闭应用内开关，或在 Android 的“通知使用权/通知读取”设置中撤销权限。关闭后待处理文本队列会清空。删除应用也会停止监听。该功能只读取 Android 系统明确授予的通知标题与正文，不登录学习平台、不读取私有数据库/Cookie、不调用非公开接口。应用关闭/被系统强制停止期间，系统服务可能延迟交付；通知会在应用可处理时生成待办。Windows 不具备此能力，仍可粘贴消息文本。

通知格式由学习平台和 Android 版本决定。通知如果已被清除、平台只发送“您有一条新消息/请点击查看”且没有作业正文，助手无法从系统通知恢复隐藏内容；请在学习通/智慧树页面打开作业详情后使用后续提供的页面/导入方式。没有出现在通知里的截止时间不会被补猜；目前只对包含明确任务词的通知创建待办。通知监听使用 Android 当前活动通知回扫和系统新通知回调；用户需保持应用通知读取授权、勾选正确的平台应用，并按手机厂商设置允许后台运行。
