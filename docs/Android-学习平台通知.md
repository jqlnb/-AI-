# Android 学习平台通知接入

1. 安装 Android APK 并登录账号（登录用于同步任务，不是读取学习平台账号）。
2. 打开“消息识别 → 学习平台通知接入”，点击“打开 Android 通知授权”。在系统页面里只为本应用打开通知读取权限，再返回助手。
3. 让学习通或智慧树发出一条作业通知。通知监听器只登记应用名称与包名；默认不会处理任何应用正文。
4. 在助手页面勾选检测到的平台应用，再打开“启用已选择的应用”。其他应用仍会被忽略。
5. 作业通知标题/正文会在手机本地解析为待办并同步到 Supabase。截止时间未明确时留空并标记“截止时间待补充”。同一 Android 通知通过稳定来源 ID 去重。

要停止接入，可关闭应用内开关，或在 Android 的“通知使用权/通知读取”设置中撤销权限。关闭后待处理文本队列会清空。删除应用也会停止监听。该功能只读取 Android 系统明确授予的通知标题与正文，不登录学习平台、不读取私有数据库/Cookie、不调用非公开接口。应用关闭/被系统强制停止期间，系统服务可能延迟交付；通知会在应用可处理时生成待办。Windows 不具备此能力，仍可粘贴消息文本。

通知格式由学习平台和 Android 版本决定。没有出现在通知里的课程、任务详情和截止时间不会被补猜；目前只对包含“作业、任务、测验、考试、提交、截止、课程设计、实验报告”等明确任务词的通知创建待办。请在真实设备上检查自动识别结果并按需编辑。
